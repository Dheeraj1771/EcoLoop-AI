# 🌍 Overview

Commercial buildings account for a significant portion of global energy consumption, with HVAC (Heating, Ventilation and Air Conditioning) systems representing one of the largest operational loads.

Most traditional Building Management Systems rely on static schedules or simple rule-based automation, making them incapable of adapting intelligently to changing environmental conditions and occupant comfort.

**EcoLoop** introduces a cognitive automation layer that continuously observes the environment, reasons over live telemetry using an AI model, validates every decision through deterministic safety checks, and safely controls HVAC operations inside a physics-based simulation.

The result is an intelligent **closed-loop HVAC optimization system** capable of reducing unnecessary energy consumption without compromising occupant well-being.

---

# 🚨 Problem Statement

Traditional HVAC control systems suffer from several critical limitations:

- ❌ Fixed schedules waste energy during varying occupancy.
- ❌ Rule-based automation lacks contextual reasoning.
- ❌ Existing systems cannot dynamically balance comfort and efficiency.
- ❌ AI-only control introduces hallucination and safety risks.
- ❌ Digital simulations often drift away from real-world conditions.

These limitations lead to:

- Increased operational costs
- Higher carbon emissions
- Reduced occupant comfort
- Unsafe automated decisions

---

# 💡 Solution

EcoLoop combines:

- 🧠 Large Language Models
- 🏢 Physics-based Building Simulation
- 🔄 Real-Time Telemetry
- 🛡 Deterministic Safety Validation
- ⚡ Closed-Loop Autonomous Control

Unlike traditional automation systems, EcoLoop continuously learns the current building state and safely adapts HVAC behaviour in real time.

Instead of replacing existing Building Management Systems, EcoLoop functions as an intelligent optimization layer that enhances them.

# ⚙ Project Workflow

## 🟢 Phase 1 — Listen (Telemetry)

PyEnergyPlus continuously streams:

- Room temperature
- Indoor environmental conditions
- Human comfort metrics

directly into the local Python environment.

---

## 🟡 Phase 2 — Think (Reasoning)

The telemetry is securely passed through the **Model Context Protocol (MCP)** to **Llama-3.1-8B** hosted on Groq.

The AI determines:

- Optimal HVAC setpoint
- Comfort-aware adjustment
- Energy-efficient operating state

---

## 🔴 Phase 3 — Protect (Safety Firewall)

Before execution, every AI-generated command is intercepted.

The Python validation layer:

- verifies temperature thresholds
- enforces ASHRAE PMV comfort limits
- blocks unsafe commands
- guarantees deterministic behaviour

No unsafe AI decision is ever allowed to reach the HVAC controller.

---

## 🔵 Phase 4 — Execute (Closed Loop)

Validated commands are injected back into EnergyPlus.

The simulator immediately reflects:

- Updated temperatures
- New comfort values
- Revised telemetry

which begins the next optimisation cycle.

# 🛡 Safety & Risk Mitigation

## 🛡 The Human Shield

Large Language Models can occasionally generate unsafe recommendations.

EcoLoop prevents this by introducing a deterministic Python firewall that validates every AI action before execution.

Algorithms never overrule human comfort.

---

## 🔄 Graceful Fallback

If connectivity to the Groq API is interrupted:

- AI reasoning pauses immediately.
- EcoLoop automatically restores the building's native baseline HVAC schedule.
- Building operations continue safely without interruption.

---

## 🌐 Continuous Calibration (Living Twin)

To eliminate **Sim-to-Real Drift**, EcoLoop continuously ingests live telemetry from the simulated environment.

This creates a continuously synchronised digital twin that accurately mirrors the current room state throughout operation.

# 🚀 Installation

## Prerequisites

- Python **3.8+**
- EnergyPlus installed
- Groq API Key
- Git

---

## Clone the Repository

```bash
git clone https://github.com/yourusername/EcoLoop.git

cd EcoLoop
```

---

```bash
pip install -r requirements.txt
```

---
